# my little world

개인 미니홈페이지와 프론트엔드 포트폴리오의 첫 구현입니다. 승인된 명세에 따라 한 화면 안에서 Observe, Connect, Reflect를 전환합니다. 프로젝트 및 기록은 현재 교체 가능한 데모 콘텐츠입니다.

## 실행

```sh
npm install
npm run dev
```

프로덕션 빌드 확인은 `npm run build`, 빌드 결과 미리보기는 `npm run preview`를 사용합니다.

## 콘텐츠 편집

- Observe 기록과 Connect / Reflect 글은 `src/content.ts`에 모아 두었습니다. 글 상세는 에디토리얼 뷰어에서 읽힙니다.
- Connect / Reflect 글은 `?article=<id>` 주소로 별도 읽기 화면을 열며, 화면의 BACK 버튼과 브라우저 뒤로 가기로 원래 챕터에 돌아옵니다.
- 모든 초기 글은 인터페이스에서 데모임을 표시하며 실제 경력이나 경험을 주장하지 않습니다.
- 글이 늘어나고 비개발자가 수정할 필요가 생기면 TypeScript 배열을 Markdown 파일로 옮기는 방식을 우선 권장합니다. 글은 빌드 시 정적 데이터로 불러오고, CMS는 발행 빈도와 공동 편집 수요가 생길 때 선택하면 됩니다.

## Tonight's Sky 데이터

현재 화면 값은 `src/sky.ts`의 `DEMO_SKY`이며 명세에 실린 `2026-10-25` 시안 데이터입니다. 실제 천문 계산이나 일일 갱신은 구현되지 않았습니다.

실제 연결 전에는 서울 좌표, KST, 날짜 경계를 포함해 정확도를 검증하고 출처와 갱신 시각을 함께 표기해야 합니다. 달 위상·조명률·보름달 시각은 검증된 천문력 라이브러리 또는 신뢰 가능한 API를 선택하고, 24절기는 한국천문연구원 등 공식 자료/API를 확인해 연결하는 것을 권합니다. 태양의 황도 별자리와 관측 가능한 밤하늘 별자리는 별도 데이터로 다뤄야 합니다.

## 기술 선택

저장소에 앱이나 패키지 설정이 없어 가벼운 React + TypeScript + Vite 구성을 선택했습니다. 우주 그래픽은 CSS로 구현했고, 별도 이미지/컴포넌트 라이브러리 및 런타임 폰트 다운로드 의존성은 두지 않았습니다. 콘텐츠와 데모 하늘 값은 UI 코드와 분리했습니다.
